# ADR-0001: В-memory storage

## Статус
Принят

## Контекст
Календарь бронирования услуг нуждается в хранении типов встреч и бронирований. Изначально требования указывают, что "Данные можно хранить в памяти процесса. В этом случае перезапуск сбрасывает записи" (Данные можно хранить в памяти процесса. В этом случае перезапуск сбрасывает записи).

## Решение
Всем доменным данным (MeetingTypeCatalog и BookingRepository) хранить в оперативной памяти с использованием Java-коллекций (CopyOnWriteArrayList и ReentrantLock). Бэкенд не использует базу данных. Все данные при перезапуске приложения очищаются.

### Положительные следствия
- **Простота**: Нет необходимости настраивать базу данных, миграции или управление соединениями. Легче разработка и тестирование локально.
- **Скорость**: Операции в памяти быстрее, чем round-trips к базе данных.
- **Соответствие требованиям**: Выполняет явное требование "Данные можно хранить в памяти процесса."
- **Минимальные операционные накладные расходы**: Нет бэкапов базы данных, проблем с масштабированием или пулом соединений.

### Отрицательные следствия
- **Потеря данных при перезапуске**: Все бронирования и типы встреч очищаются при перезапуске приложения. Это допустимо для учебного проекта, но не для production.
- **Нет сохранности**: Не может выжить при перезагрузке сервера или сбоях.
- **Не подходит для production**: Для реального деплоя понадобится добавить базу данных (вероятно, PostgreSQL).

## Рассмотренные альтернативы
- **PostgreSQL с начала**: Предоставляет сохранность, но добавляет сложность, требует настройки базы данных, миграций и управления соединениями. Перебор для учебного проекта.
- **Встраиваемая H2 база данных**: Предоставляет сохранность с минимальными настройками, но все равно добавляет зависимость и сложность.

## Связано с
- `CalendarTime.WINDOW_DAYS` — связанное ограничение, что окно составляет 14 дней, которое для реального использования понадобится сохранность
- `MeetingTypeCatalog` — реализация in-memory каталога
- `BookingRepository` — in-memory хранение бронирований
