## Основные сущности предметной области (из кода)

| Термин | Код | Определение |
|---|---|---|
| **Встреча (MeetingType)** | `com.example.calendar.meeting.MeetingType` (record) | Тип встречи, который заводит владелец календаря. Неизменяемый record с полями `id`, `name`, `description`, `durationMinutes`. Создается и редактируется через админку. Предварительно загружены два типа: `meeting-15` (15 минут) и `meeting-30` (30 минут). |
| **Бронирование (Booking)** | `com.example.calendar.booking.Booking` (record) | Запись гостя на встречу. Поля: `id`, `meetingTypeId`, `meetingTypeName`, `date`, `startTime`, `endTime`, `guestName`, `guestAvatar`, `note` (опционально). Часовой пояс: Asia/Almaty. Хранилище: в памяти процесса; сброс при перезапуске. |
| **Слот (Slot)** | `com.example.calendar.booking.Slot` (record) | Временной интервал, помеченный как доступный/недоступный для данной даты. Поля: `startTime`, `endTime`, `available`. Генерируется per MeetingType и дату. |

## Доменные сервисы (из кода)

| Термин | Код | Определение |
|---|---|---|
| **Бронинг-сервис (BookingService)** | `com.example.calendar.booking.BookingService` | Основной сервис с методами: `slots(meetingTypeId, date)` → `List<Slot>`, `create(meetingTypeId, date, startTime, guestName, guestAvatar, note)` → `Booking`, `upcoming()` → `List<Booking>`. Потокобезопасен через `ReentrantLock`. Enforces: booking window, working hours, non-overlapping constraint, past-time rejection. |
| **Каталог типов встреч (MeetingTypeCatalog)** | `com.example.calendar.meeting.MeetingTypeCatalog` | In-memory каталог (CopyOnWriteArrayList). Методы: `findAll()`, `findById(id)`, `create(name, description, durationMinutes)`, `update(id, name, description, durationMinutes)`, `delete(id)`. Доступно через админку. |
| **Исключение MeetingTypeNotFoundException** | `com.example.calendar.meeting.MeetingTypeNotFoundException` | Выбрасывается при попытке записи/получения слота с несуществующим ID типа встречи. |

## Время и ограничения (из кода + спецификация)

| Термин | Определение |
|---|---|
| **Часовой пояз** | `Asia/Almaty` (Казахстан). Все даты/время находятся в этом поясе. |
| **Рабочие часы** | 09:00–13:00 (утро) и 14:00–18:00 (день). Перерыв на обед 13:00–14:00 исключен. |
| **Окно записи** | 14 календарных дней от сегодняшней даты, включительно. Окно сдвигается вперед с протеканием времени. Формула: `today.plusDays(WINDOW_DAYS - 1)`. |
| **WINDOW_DAYS** | Константа = 14 (определена в `CalendarTime.java`). |
| **Шаг слота** | Фиксированный шаг между доступными началами слотов = длительность MeetingType в минутах. Например, тип 15 мин → слоты в 09:00, 09:15, 09:30, ... |
| **Ограничение на наложение интервалов** | Две брони не могут пересекаться. Даже разные типы встреч не могут overlapping. Новое бронирование может начинаться ровно в момент окончания предыдущего (граничное условие допускается). Enforced через `findOverlapping()` + `ReentrantLock`. |
| **Отказ от прошедшего времени** | Записи на прошедшие даты/время отвергаются. Проверяется через `isPast(date, time)` сравнивание с `ZonedDateTime.now(ZONE)`. |
| **Минимальный отсрочнный контроль** | Запись не может быть произведена на время, которое уже прошло в текущий день. |

## Правила и инварианты (из доменных правил + код)

- **Единственный владелец**, нет авторизации для гостей.
- **Хранилище в памяти**: перезапуск очищает все данные (брони + типы встреч).
- **Правила действуют одновременно для одновременных запросов**: защищено `ReentrantLock` в BookingService.
- **Длина = Длина встречи**: Длина слота точно соответствует `durationMinutes` выбранного MeetingType.
- **Шаг = длительность**: Доступные начала слотов шагом соответствуют длительности (например, шаг 15 мин или 30 мин).
- **Никаких наложений, даже между разными типами**: `findOverlapping()` проверляет все существующие брони.
- **Следующая может начинаться ровно когда предыдущая заканчивается**: граничное условие допускается.
- **Окно записи: 14 дней от сегодняшнего, включительно**.
- **Только рабочие часы**: 09:00–13:00 и 14:00–18:00 Asia/Almaty.
- **Перерыв на обед 13:00–14:00**: слоты не генерируются.
- **Отказ от прошедшего времени**: нельзя записаться на прошедшее время.
- **Владелец создает/редактирует MeetingTypes** в админском интерфейсе.
- **Примечание к бронированию опционально**.
- **Интерфейс на русском языке**.
- **Источник правды API**: `api/main.tsp` → OpenAPI 3 → TypeScript SDK (`@hey-api/openapi-ts`).
- **Сгенерированный SDK находится в** `frontend/src/api/generated` **и игнорируется git**.
- **Команды**: `mise run check` (все проверки), `mise run lint`, `mise run typecheck`, `mise run test`.
